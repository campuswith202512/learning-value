# 学びに求める価値｜年代・属性別 レーダーチャート＆総合分析

就学児（本人・保護者）、中高生（本人・保護者）、大学生、社会人（20・30代／40・50代）、主婦、経営者、高齢者の**全10セグメント**における「学びに求める価値」を、公的調査・民間リサーチ・SNS定性分析から共通の**7項目**で可視化したインタラクティブ・レーダーチャートサイトです。

## 公開URL
https://campuswith202512.github.io/learning-value/

## 主な機能
- 最大4属性を重ね合わせ比較できるインタラクティブ・レーダーチャート（6種の比較プリセット付き）
- 仮説検証用スコア調整シミュレーター
- 全10属性ミニレーダー一覧ギャラリー
- ライフステージ8段階のU字カーブ推移グラフ
- 属性別ディープ分析（調査ファクト × SNS本音 × 企画示唆）
- ヒートマップ付きスコア一覧表（ソート・CSVダウンロード・SVGチャート保存対応）
